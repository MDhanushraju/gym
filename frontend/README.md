# FormFit AI Gym - Frontend Application

React 18 + Vite + Tailwind CSS + MediaPipe client web application for FormFit.

## Features
- **Pure Client-Side AI Coach:** Real-time MediaPipe WebAssembly pose detection.
- **Biomechanical Movement Engines:** Curated for Basic Squats and Standard Pushups.
- **Mobile-Friendly Camera Control:** Seamless front/selfie and rear camera switching with aspect-corrected mirroring.
- **Synchronized Two-Device Camera Support:** Pair a second phone via QR code or short join code to track back-view posture.
- **100% Privacy:** Zero video frames are ever transmitted over the network.

## Quick Start

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Start development server accessible over local network (for mobile devices)
npm run dev -- --host

# Build for production
npm run build
```
